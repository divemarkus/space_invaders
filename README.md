# Space Invaders

A classic arcade game clone in C++ using GLFW and OpenGL. This is a companion to [this series of tutorial posts](http://nicktasios.nl/posts/space-invaders-from-scratch-part-1.html).

## Install and Run

### Mac
```bash
brew install glfw glew
./build.sh
chmod +x build/bin/space_invaders
./build/bin/space_invaders
```

### Linux
```bash
# Ubuntu/Debian
sudo apt install libglfw3-dev libglew-dev cmake g++
./build.sh
./build/bin/space_invaders
```

## Controls

- **Left/Right Arrow**: Move player
- **Space**: Fire
- **Escape**: Quit
